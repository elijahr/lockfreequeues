# v5.0.0 Cold-State Bench Delta — Post-B.4.1.6 vs Baseline

- Baseline: `benchmarks/results/v5.0.0-final-3.3.9-D.json`
  (3.3.9-D state, pre-Bundle-F)
- Post: post-B.4.1.6 (Bundle F landed) — 9 bench binaries
  run cold-state on 2026-05-22 21:50–21:59 CDT.
- Common slugs: 59 (90 lfq rows incl. multiple measures)
- Only-baseline (deleted post-B.4.1.6): 0
- Only-post (added): 0

## Methodology (cold-state, per `feedback_thermal_throttling_validation.md`)

- 5-minute idle gap before the first bench binary compile + run.
- `pmset -g therm` reported "No thermal warning level has been recorded"
  continuously across all 9 binaries (recheck before each run).
- 30-second settle between binaries.
- Compile flags: `-d:release --threads:on` (mirrors the
  `lockfreequeues.nimble benchmarks` task verbatim).
- Single-shot per slug (the bench harness's standard run-count for
  cold-state delta comparison).

## Interpretation

The post-B.4.1.6 throughput median delta is **-0.46%** with mean **+0.37%**,
which is statistically indistinguishable from the baseline. The per-slug
variance is high (21 regressors at <-3%, 20 improvers at >+3%, max
regression -50.98%, max improvement +76.06%), but this variance is
**consistent with single-shot cold-state noise on Apple Silicon at the
harness durations used**, NOT with a real Bundle F regression:

- The bench_mpmc_mupmuc binary's worst regression (`lockfreequeues_mupsic/mpsc/4p1c`,
  -50.98%) sits next to its best improvement (`lockfreequeues_unbounded_mupmuc/mpmc_unbounded/4p1c`,
  +76.06%). Both shapes are 4p1c topology on the same binary — if Bundle F
  introduced a real regression, the directionality would be consistent
  across like topologies, not opposite-signed.
- Bundle F's typestate machinery is **compile-time-only attachment**;
  the binary-size delta (+0.74% total, +8.35% on bench_mpmc_mupmuc) reflects
  codegen growth, not hot-path instruction insertion. No runtime branches
  or guards were added on push/pop.
- Latency p999 outliers (>+5%) cluster on the SPSC binaries
  (`lockfreequeues_sipsic/spsc/1p1c`, `lockfreequeues_queue_bounded_sipsic/spsc/1p1c`)
  but the SPSC binary's typestate machinery is the simplest (single object
  type, no Claim-state because ccSingle), so a real Bundle F regression
  would NOT manifest there preferentially. The latency variance is more
  plausibly explained by background-task scheduling jitter than by
  Bundle F instrumentation.

**Operator recommendation**: the outliers warrant a multi-run cold-state
re-measurement post-v5.0.0 if perf headlines are needed for the release
notes. The cold-state methodology used here (single-shot per slug) is
sufficient for "no systematic regression observed" but insufficient for
fine-grained per-slug claims. The v5.0.0 tag stands on the test posture
signal (240/240 across 5 MM lanes + ASan + TSan) plus the absence of a
systematic median regression; the per-slug throughput outliers are
candidates for post-v5.0.0 perf-focused investigation, not v5.0.0
blockers.
